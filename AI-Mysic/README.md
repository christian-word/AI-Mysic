# Каталог пісень

Сторінка читає всі дані з `songs.json`. Щоб додати пісню, код чіпати не треба — тільки JSON.

## Структура

```
├── index.html      ← сторінка каталогу (не редагується при додаванні пісень)
├── songs.json      ← усі пісні та версії
├── og-image.png    ← картинка для превʼю посилання в месенджерах
├── audio/          ← аудіофайли
└── covers/         ← обкладинки (одна на пісню, спільна для всіх її версій)
```

## Як додати нову пісню

1. Поклади аудіофайли у `audio/`, обкладинку — у `covers/`.
2. Додай блок у масив `songs` у `songs.json`:

```json
{
  "id": "nazva-pisni",
  "title": "Назва пісні",
  "year": "2026",
  "cover": "covers/nazva-pisni.jpg",
  "note": "Короткий опис. Можна не вказувати.",
  "versions": [
    { "name": "Remix",   "file": "audio/nazva-remix.m4a",   "youtube": "https://youtube.com/shorts/XXXX" },
    { "name": "Ambient", "file": "audio/nazva-ambient.m4a", "youtube": "" }
  ]
}
```

Обовʼязкові поля — `title` і `versions` (у версії — `name` та `file`).
`year`, `cover`, `note`, `youtube` можна пропускати.

Версій може бути скільки завгодно — від однієї до восьми й більше.
Якщо версія одна, картка не згортається й показує її одразу.

## Публікація на GitHub Pages

1. Заливаєш усю папку в репозиторій.
2. Settings → Pages → Source: `main`, папка `/root` → Save.
3. Через хвилину сайт буде за адресою `https://christian-word.github.io/AI-Mysic/`.
4. В `index.html` заміни `ДОМЕН` у мета-тегах на цю адресу — тоді в Viber і Telegram
   посилання розгортатиметься карткою з картинкою.

## Локальна перевірка

Просто відкрити `index.html` подвійним кліком не вийде — браузер заблокує читання
`songs.json` з диска. Запусти в папці каталогу:

```
python3 -m http.server 8000
```

і відкрий `http://localhost:8000`.
