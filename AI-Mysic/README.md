# Каталог AI Mysic

Три рівні: **альбом → трек → версії треку**. Не всі треки багатоверсійні —
трек з однією версією одразу показує плеєр, без розгортання.

Сторінка (`index.html`) читає все з `albums.json`. При додаванні нових
альбомів, треків чи версій код не редагується — тільки JSON.

## Структура

```
├── index.html      ← сторінка каталогу (не редагується при додаванні контенту)
├── albums.json     ← усі альбоми, треки, версії
├── og-image.png    ← картинка для превʼю посилання в месенджерах
├── audio/          ← аудіофайли
└── covers/         ← обкладинки (одна на альбом)
```

## Формат albums.json

```json
{
  "title": "AI Mysic",
  "subtitle": "Короткий підзаголовок каталогу",
  "playlist": "https://youtube.com/playlist?list=...",
  "albums": [
    {
      "title": "Назва альбому",
      "year": "2026",
      "cover": "covers/album-1.jpg",
      "tracks": [
        {
          "title": "Трек без версій",
          "versions": [
            { "file": "audio/track1.m4a", "youtube": "https://youtube.com/shorts/..." }
          ]
        },
        {
          "title": "Трек з кількома версіями",
          "versions": [
            { "name": "Remix",   "file": "audio/track2-remix.m4a",   "youtube": "" },
            { "name": "Ambient", "file": "audio/track2-ambient.m4a", "youtube": "" }
          ]
        }
      ]
    }
  ]
}
```

Правила:
- У треку з **однією** версією поле `name` можна не вказувати — покажеться назва треку.
- У треку з **кількома** версіями `name` варто вказувати (Remix, Acoustic, тощо) — інакше всі підпишуться як "Версія".
- `year`, `cover`, `youtube`, `playlist` — необовʼязкові.
- Версій у треку може бути скільки завгодно — хоч 8, хоч 1.

## Як додати новий альбом

1. Поклади аудіофайли у `audio/`, обкладинку — у `covers/`.
2. Додай новий обʼєкт у масив `albums` за зразком вище.
3. Заливаєш зміни в репозиторій — сторінка підхопить їх сама.

## Публікація на GitHub Pages

1. Заливаєш усю папку в репозиторій.
2. Settings → Pages → Source: `main`, папка `/root` → Save.
3. Через хвилину сайт буде за адресою `https://christian-word.github.io/AI-Mysic/`.
4. В `index.html` заміни `ДОМЕН` у мета-тегах на цю адресу — тоді в Viber і Telegram
   посилання розгортатиметься карткою з картинкою.

## Локальна перевірка

Просто відкрити `index.html` подвійним кліком не вийде — браузер заблокує читання
`albums.json` з диска. Запусти в папці каталогу:

```
python3 -m http.server 8000
```

і відкрий `http://localhost:8000`.
